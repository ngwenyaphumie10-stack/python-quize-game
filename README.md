# Python Quiz Game

This is a simple quiz game built using Python.

The program asks the user random computer science questions and keeps track of the high score.

## Features

- Random quiz questions
- Multiple choice answers
- Score calculation
- High score saved in a file
- Simple command-line interface

## How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Run the program using:

python quiz-game.py

## Files in the Project

quiz-game.py  -> Main quiz program  
highscore.txt -> Stores the highest score  
README.md     -> Project description
